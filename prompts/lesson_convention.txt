When a level rule applies to a labelled class and the report gives only one example value, the class is a real-world category that the label does not name: a named grouping that exists in this domain, such as an organisation, an alliance, an official list or a standard classification. Feedback that another value is treated like the example, and that some other value is not, tells you which category it is: choose the best-known named grouping that contains the example and the confirmed value and excludes the rejected one. Do not construct a category from a property you read in the descriptions, such as a region, a type of government, a climate or a size.
