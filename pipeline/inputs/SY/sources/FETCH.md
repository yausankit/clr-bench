# FETCH — SY sources

All fetches were made on 2026-10-19 (UTC) on a Linux build host.  GitHub / NLM / RxNav / WHOCC were reached
directly; Wikipedia and Wikimedia pageviews went through the provided reverse proxy
`$HTTPS_PROXY` with one request at a time (>= 2 s between MediaWiki API calls, >= 0.5 s
between pageview calls, exponential backoff on 429).

## (a) Data snapshot — Synthea synthetic patients

- File: `raw/synthea_sample_data_csv_nov2021.zip` (58,771,261 bytes)
- URL: https://raw.githubusercontent.com/synthetichealth/synthea-sample-data/main/downloads/synthea_sample_data_csv_nov2021.zip
- Version: the `nov2021` CSV sample release of `synthetichealth/synthea-sample-data`.
- `sources/synthea/{patients,medications,conditions,procedures}.csv` are the four members of that
  zip, extracted unchanged (verified by SHA-256 against the zip members, see `SHA256SUMS`).
- All records are synthetic; no real patients.  Time period used by the chains: 2015-01-01 ..
  2021-12-31; snapshot date 2026-10-16 (given by the input card).

## (b) Coding / classification sources used to build universes and lists

| Path | Source URL | Version / date |
|---|---|---|
| `raw/mesh/desc2025.xml` | https://nlmpubs.nlm.nih.gov/projects/mesh/2025/xmlmesh/desc2025.xml | MeSH 2025 |
| `raw/mesh/mtrees2025.bin` | https://nlmpubs.nlm.nih.gov/projects/mesh/2025/meshtrees/mtrees2025.bin | MeSH 2025 |
| `raw/rxnav_ingredients/<rxcui>.json` | https://rxnav.nlm.nih.gov/REST/rxcui/<rxcui>/related.json?tty=IN | RxNav REST, 2026-10-19 |
| `raw/atc/class_*.html` | https://atcddd.fhi.no/atc_ddd_index/?code=<code>&showdescription=no | WHOCC ATC/DDD Index, 2026-10-19 |
| `raw/snomed/expand_<code>.json` | https://tx.fhir.org/r4/ValueSet/$expand (is-a filter) | SNOMED CT International 20250201 (per expansion parameter), 2026-10-19 |
| `raw/snomed/names.json` | https://tx.fhir.org/r4/CodeSystem/$lookup?system=http://snomed.info/sct&code=<code> | same release |

`raw/atc/search_*.html` are the name-search pages used to discover which ATC classes exist for the
Synthea drug names.  `sources/ingredient_by_rxcui.tsv` is the RxCUI -> ingredient map extracted from
`raw/rxnav_ingredients/` (generated by `build_universes.py`).

Count semantics used for `official_count`: an ATC list counts the level-5 substances listed under the
class (intermediate group headers are not substances); a MeSH tree list counts the descriptors that
have a tree number under that node; a MeSH pharmacological-action list counts the descriptors that
carry that action; a SNOMED list counts the entries of the `is-a` ValueSet expansion (the concept plus
its descendants, `expansion.total`).  `out_of_universe` holds exactly the source members that are not
values of this dataset's 2015-2021 universe.

`raw/crosswalk/procedure.tsv` is **derived, not downloaded**: SNOMED procedure code -> MeSH E-tree
descriptor, written from the SNOMED description with the basis recorded in column 3.  It is needed
because exact-name matching only reaches 25 of the 175 procedure labels; every meSH-based procedure
list member is still verified back to a MeSH line in `desc2025.xml` (see `SPOTCHECK.tsv`).

## (c) Salience

- Wikipedia search: https://en.wikipedia.org/w/api.php?action=query&list=search&srsearch=<name>&srlimit=3
- Pageviews: https://wikimedia.org/api/rest_v1/metrics/pageviews/per-article/en.wikipedia/all-access/user/<title>/monthly/20251001/20260930
- Raw JSON responses are kept in `salience/raw/` (`search_<universe>_<list>.json`,
  `pageviews_<universe>_<list>.json`); `build_salience.py` recomputes `salience/<universe>.tsv`
  from them.  The first search hit is used only when its title is lexically related to the list name
  (shared word, shared prefix of >= 5 letters, or one word inside the other); otherwise the list gets
  salience 0 and stays in the input.  `note` in the TSV records which word made the match.

## (d) Reproducing

```
python3 build_universes.py            # needs sources/synthea and raw/rxnav_ingredients, raw/mesh
python3 build_lists.py                # needs raw/mesh, raw/atc, raw/snomed, raw/crosswalk
python3 build_salience.py             # needs salience/raw/*.json
```
Running the three scripts twice produces byte-identical `universes/`, `lists/` and `salience/*.tsv`.

## (e) ADD_SY_a5 medicine-list additions (2026-10-20)

- Source inputs were copied from `agents/SHRINK_SY_a1/inputs/SY` and verified with `diff -r`.
- The 24 new medicine lists use only formally titled tables/sections/classes: AGS Beers 2023
  Table 6, EU(7)-PIM Table 1, STOPP/START v3 Section L, CredibleMeds Composite All-QTDrugs,
  two labelled FDA Table 1 columns, four WHO EML 2023 sections, NIOSH 2024 Tables 1-2,
  WHO ATC/DDD L02, and eleven NLM RxClass classes.  Exact files, URLs, extraction methods, and
  count semantics are recorded in `raw/add/r5/FETCH.md` and in
  `raw/add/r5/manifests/official_members.json`.
- Wikipedia search/pageviews for the new lists were fetched on 2026-10-20 through
  `$HTTPS_PROXY` with 2.0 s search spacing, 0.6 s pageview spacing, and exponential
  backoff on HTTP 429.  Raw responses are `salience/raw/{search,pageviews}_medicine_<list>.json`.
- Relevant deterministic scripts are `extract_manifest_add_r5.py`, `build_salience_add_r5.py`,
  `build_lists_add_r5.py`, `apply_templates_add_r5.py`, and `spotcheck_add_r5.py`.  The first
  reads only stored raw sources; the remaining scripts read the manifest/salience/raw files and
  preserve the pre-existing 47 lists and templates byte for byte.
