A security firm audits client web sites: the hosts of each site are scanned and every finding is recorded against the host where it was observed; the client's report totals the recorded findings per site.

Write one Python 3 program in a single code block. Define solve(data), where data is the parsed JSON input (a dict), and return the answer as an int.

Input:
The top-level JSON object has one key, sites. Each site has id, name, and hosts. Each host has id, hostname, tld, and scans. Each scan has id, profile, and findings. Each finding has id, title, cwe, language, and severity.

Each finding counts once toward the total of the site that owns the host on which it was recorded; a site's total is the number of its findings that are counted.
Return the largest total among the sites in the input, as an int.

Field notes:
- A finding whose cwe is 'CWE-766' is in client folio G3.
- A finding whose language is 'en' is in audit lane 39.
- A host whose tld is 'ng' is in reporting band V-65.
- A finding whose cwe is 'CWE-117' is in review line X3.
Each label in the field notes stands for a real-world category of values; a note gives one member of that category, and the label's name does not say which category it is.

Level rules:
L1: From this level on, findings in client folio G3 are not counted.
L2: From this level on, findings in audit lane 39 are not counted.
L3: From this level on, hosts in reporting band V-65 are not counted.
L4: From this level on, findings in review line X3 are not counted.

Some hidden test inputs are the example input below with one or two field values changed; each is judged by the same rules.
