A multinational's finance team audits employee travel expenses: every flight segment on a submitted claim is reimbursable and is counted once for the department of the employee who filed the claim.

Write one Python 3 program in a single code block. Define solve(data), where data is the parsed JSON input (a dict), and return the answer as an int.

Input:
The input is one JSON object with four lists: departments (id, name, region), employees (id, name, department), claims (id, employee, submitted, currency, fare_amount, fare_display) and segments (id, claim, airline, departure_airport, arrival_airport, travel_date, route). employee.department and segment.claim are ids from the other lists.

Each flight segment on a submitted expense claim counts once toward the total of the department of the employee who filed that claim.
Return the sum of the totals of all departments in the input, as an int.

Field notes:
- A segment whose airline is 'British Airways' is in desk label P5.
- A segment whose arrival_airport is 'PEV' is in ledger code 35.
Each label in the field notes stands for a real-world category of values; a note gives one member of that category, and the label's name does not say which category it is.

Level rules:
L1: From this level on, segments in desk label P5 are not counted.
L2: From this level on, segments in ledger code 35 are not counted.
