A health plan's utilisation review unit totals, for each patient, the records in the patient's file that its review desk has to process: medication fills, diagnoses and procedures.

Write one Python 3 program in a single code block. Define solve(data), where data is the parsed JSON input (a dict), and return the answer as an int.

Input:
The top-level JSON object has keys patients (ids), medications, conditions and procedures.  Each record row carries the patient id and its trap field: medications have ingredient, conditions and procedures have code (and a description).

Every record in a patient's file adds one to that patient's review total: each medication fill, each diagnosis and each procedure counts one.
Return the sum of the totals of all patients in the input, as an int.

Field notes:
- A condition whose code is 443165006 is in review tag W8.
- A procedure whose code is 11466000 is in intake mark 85.
- A medication whose ingredient is 'Doxorubicin' is in ledger mark A-57.
- A condition whose code is 195662009 is in batch lane Z3.
Each label in the field notes stands for a real-world category of values; a note gives one member of that category, and the label's name does not say which category it is.

Level rules:
L1: From this level on, conditions in review tag W8 are not counted.
L2: From this level on, procedures in intake mark 85 are not counted.
L3: From this level on, medications in ledger mark A-57 are not counted.
L4: From this level on, conditions in batch lane Z3 are not counted.
