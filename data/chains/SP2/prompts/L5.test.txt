A sports marketing agency reconciles sponsorship activation counts for sponsor brands before settlement.

Write one Python 3 program in a single code block. Define solve(data), where data is the parsed JSON input (a dict), and return the answer as an int.

Input:
JSON with sponsor_brands, contracts, and activations; each activation points to one contract, and each contract points to one sponsor brand.

Each activation is one unit in the total of the sponsor brand reached through its contract; an activation is left out when one of its trap-field values is rejected.
Return the sum of the totals of all sponsor brands in the input, as an int.

Field notes:
- An activation whose club is 'Real Madrid' is in audit lane X5.
- An activation whose co_sponsor is 'Microsoft' is in review code 55.
- An activation whose market_country is 'DE' is in review tag Y-25.
- An activation whose club is 'Inter Milan' is in settlement lane D3.
- An activation whose co_sponsor is 'ASML' is in handling class 20.
Each label in the field notes stands for a real-world category of values; a note gives one member of that category, and the label's name does not say which category it is.

Level rules:
L1: From this level on, activations in audit lane X5 are not counted.
L2: From this level on, activations in review code 55 are not counted.
L3: From this level on, activations in review tag Y-25 are not counted.
L4: From this level on, activations in settlement lane D3 are not counted.
L5: From this level on, activations in handling class 20 are not counted.
