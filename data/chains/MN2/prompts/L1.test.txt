A manufacturing company's procurement audit team reviews raw-material purchase lots by factory before approving sourcing exceptions.

Write one Python 3 program in a single code block. Define solve(data), where data is the parsed JSON input (a dict), and return the answer as an int.

Input:
JSON with a top-level 'factories' array. Each factory has a factory_id and a purchase_orders array; each purchase order has a purchase_order_id and a lots array. Each lot has lot_id, origin_country, carrier and material.

Each purchase lot counts once toward its factory unless a level rule excludes one of the lot's field values.
Return the sum of the totals of all factories in the input, as an int.

Field notes:
- A lot whose origin_country is 'DE' is in ledger mark P8.
Each label in the field notes stands for a real-world category of values; a note gives one member of that category, and the label's name does not say which category it is.

Level rules:
L1: From this level on, lots in ledger mark P8 are not counted.
