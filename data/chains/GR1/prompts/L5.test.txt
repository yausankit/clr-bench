A research foundation reviews travel reimbursement requests for scholars attending international conferences.

Write one Python 3 program in a single code block. Define solve(data), where data is the parsed JSON input (a dict), and return the answer as an int.

Input:
A JSON object containing batches, each with its applicant records and itinerary segment records.

Each eligible itinerary segment contributes one to the total for its funding call.
Return the sum of the totals of all funding calls in the input, as an int.

Field notes:
- An applicant whose nationality is 'GB' is in travel note X5.
- A trip whose airline is 'Lufthansa' is in audit marker 55.
- An applicant whose university is 'University of Edinburgh' is in review notation Y-25.
- An applicant whose nationality is 'IT' is in routing code D3.
- A trip whose airline is 'Qatar Airways' is in expense label 20.
Each label in the field notes stands for a real-world category of values; a note gives one member of that category, and the label's name does not say which category it is.

Level rules:
L1: From this level on, applicants in travel note X5 are not counted.
L2: From this level on, trips in audit marker 55 are not counted.
L3: From this level on, applicants in review notation Y-25 are not counted.
L4: From this level on, applicants in routing code D3 are not counted.
L5: From this level on, trips in expense label 20 are not counted.
