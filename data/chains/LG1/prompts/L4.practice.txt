A corporate network gateway aggregates the proxied connections and SSH logins of its workstations into one event count per workstation.

Write one Python 3 program in a single code block. Define solve(text), where text is the whole input as one string, and return the answer as an int.

Input:
The input is plain text. The first line starts with WORKSTATIONS and lists the
workstation ids separated by |. Then come the proxy connections, one per line, as
PROXY|<record id>|<workstation>|<time>|<target host>|<target port>|<client process>|<action>,
and the SSH logins as SSH|<record id>|<workstation>|<time>|<user name>|<source address>.
Every PROXY line is one proxied connection, every SSH line is one SSH login.

Each proxy connection and each SSH login adds one event to the total of the workstation it belongs to.
Return the largest total among the workstations in the input, as an int.

Field notes:
- A proxy connection whose tld is 'ru' is in gateway lane T9.
- A proxy connection whose client_app is 'EXCEL.EXE' is in event bucket 30.
- A proxy connection whose port is 137 is in session tag F-88.
- A proxy connection whose tld is 'de' is in access lane D5.
Each label in the field notes stands for a real-world category of values; a note gives one member of that category, and the label's name does not say which category it is.

Level rules:
L1: From this level on, proxy connections in gateway lane T9 are not counted.
L2: From this level on, proxy connections in event bucket 30 are not counted.
L3: From this level on, proxy connections in session tag F-88 are not counted.
L4: From this level on, proxy connections in access lane D5 are not counted.

Some hidden test inputs are the example input below with one or two field values changed; each is judged by the same rules.
