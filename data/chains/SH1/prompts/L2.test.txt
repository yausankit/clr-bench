A port state control office aggregates vessel inspection defects for follow-up by the vessel's ship management company.

Write one Python 3 program in a single code block. Define solve(data), where data is the parsed JSON input (a dict), and return the answer as an int.

Input:
A JSON object lists companies, their ships, each ship's inspections, and the defect identifiers recorded for each inspection.

Each defect listed in an inspection counts once for the vessel's management company.
Return the sum of the totals of all ship management companies in the input, as an int.

Field notes:
- A ship whose flag_state is 'FR' is in follow-up docket D4.
- A ship whose owner_country is 'DE' is in review ledger 71.
Each label in the field notes stands for a real-world category of values; a note gives one member of that category, and the label's name does not say which category it is.

Level rules:
L1: From this level on, ships in follow-up docket D4 are not counted.
L2: From this level on, ships in review ledger 71 are not counted.
