A sports marketing agency reconciles sponsorship activation counts for sponsor brands before settlement.

Write one Python 3 program in a single code block. Define solve(data), where data is the parsed JSON input (a dict), and return the answer as an int.

Input:
JSON with sponsor_brands, contracts, and activations; each activation points to one contract, and each contract points to one sponsor brand.

Each activation is one unit in the total of the sponsor brand reached through its contract; an activation is left out when one of its trap-field values is rejected.
Return the largest total among the sponsor brands in the input, as an int.

Field notes:
- An activation whose club is 'Real Madrid' is in handling class P8.
- An activation whose co_sponsor is 'ASML' is in review tag 70.
- An activation whose market_country is 'CA' is in audit lane N-59.
- An activation whose club is 'Inter Milan' is in review code W2.
- An activation whose co_sponsor is 'Walmart' is in settlement lane 60.
Each label in the field notes stands for a real-world category of values; a note gives one member of that category, and the label's name does not say which category it is.

Level rules:
L1: From this level on, activations in handling class P8 are not counted.
L2: From this level on, activations in review tag 70 are not counted.
L3: From this level on, activations in audit lane N-59 are not counted.
L4: From this level on, activations in review code W2 are not counted.
L5: From this level on, activations in settlement lane 60 are not counted.

Some hidden test inputs are the example input below with one or two field values changed; each is judged by the same rules.
