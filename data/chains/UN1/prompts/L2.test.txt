An international education foundation reviews scholarship applications and totals cases for follow-up by funding programme.

Write one Python 3 program in a single code block. Define solve(data), where data is the parsed JSON input (a dict), and return the answer as an int.

Input:
The top-level JSON object has these keys:
- programmes: rows with applications, project_id

Each application counts once for its funding programme unless a rule excludes that application.
Return the sum of the totals of all funding programmes in the input, as an int.

Field notes:
- An applicant whose nationality is 'FR' is in review docket W8.
- A reference whose country is 'MY' is in settlement note 59.
Each label in the field notes stands for a real-world category of values; a note gives one member of that category, and the label's name does not say which category it is.

Level rules:
L1: From this level on, applicants in review docket W8 are not counted.
L2: From this level on, references in settlement note 59 are not counted.
