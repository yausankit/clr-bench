A customs broker reviews chemical import declarations and counts the declaration lines that require manual clearance.

Write one Python 3 program in a single code block. Define solve(data), where data is the parsed JSON input (a dict), and return the answer as an int.

Input:
JSON with an importers array; each importer has an id and declarations, each declaration has an id, exporter_country, and shipments, and each shipment has an id, air_carrier, and lines.

Each declaration line counts once for its importer unless the line's substance, its declaration's exporter country, or its shipment's air carrier is excluded.
Return the largest total among the importers in the input, as an int.

Field notes:
- A line whose substance is 'Hexachlorobenzene' is in intake folder X8.
Each label in the field notes stands for a real-world category of values; a note gives one member of that category, and the label's name does not say which category it is.

Level rules:
L1: From this level on, lines in intake folder X8 are not counted.

Some hidden test inputs are the example input below with one or two field values changed; each is judged by the same rules.
